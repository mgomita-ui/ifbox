# IFBOX（もしも箱）試作

「もし、こんなのがあれば」を一行で置くと6つの席が立ち、空席にAIが座って準備し、人が来たら引き継いで交代する。提案・支援・出資・納品・検収・配分・精算まで一周し、精算まで終わった案件を「型」にして二度目を速く回す。仲間内テスト用の試作。

**いまは非公開。** 席の仕組み・引き継ぎ・権限分離の細部は特許出願前。public にする条件と手順は `PUBLISH_CHECKLIST.md`。開くのは席の型・タスクの構造・台帳のスキーマ・参照実装まで。履行の記録（共有DBの中身）と運営は開かない。公開LPは別リポジトリ（ifbox-lp）。

思想は「リナックスのように作り、協同組合のように分ける」。貢献のしかたは `CONTRIBUTING.md`。ライセンスは Apache-2.0（特許条項を含む。出願との関係は弁理士確認中）。

## 動いているもの

- 本番（共有DB・AIつき）：claude.ai のアーティファクトとして公開。URLは Slack/LINE で共有（このREADMEには書かない）。
- `proto/index.html` … 本番のソース。`claude.use('db')` と `claude.use('sample')` を使うため、単体で開くとDBとAIは無効（閲覧のみ）。
- `proto/test/index.html` … DBとAIを偽物に差し替えた検証用。ブラウザで開くだけで一周の操作を試せる（データは保存されない）。
- `mock/index.html` … 全貌を見せるクリック可能なモック（データは例）。

## 画面

| 画面 | 寄せた先 | 中身 |
|---|---|---|
| 探す | メルカリ | 検索・チップ・4列グリッド・成約済バッジ・支援バー・未読 |
| 案件 | ランサーズ | 提案（席・金額・納期）→発案者が採用→席に座る／AIの最低ライン／メッセージ／記録 |
| 先に買う | 購入型CF | 目標額・期限・リターン。目標到達後、発案者が買い手を確定（段階2） |
| 資金を出す | 出資型CF | 目標額・使途・持分%。意向の記録のみ。募集・払込は登録事業者 |
| 納品・検収 | App Store | 検収基準を公開（採用の前提）→納品→全項目合格で確定／理由必須で差し戻し |
| 台帳 | 表 | 採用済み対価＋補足行（自己申告名で確認、編集で解除） |
| 型・比較 | 独自 | 精算済み案件を型に→次の投稿で適用→元案件と時間・原価を比較（条件固定・実時計・推計表示・比較不能理由）→二度目の確認 |
| 納品・検収 | GitHub | 成果物は固定版（名称・本文・変更要約）。型で固定コピー→適用先で取り込み担当と使用区分 |
| 手番 | 独自 | 案件をまたいで、自分が次に動くものだけ（席の状態と取り込み状態から都度計算） |
| 配分 | 独自 | 三層＋IFBOX単価表（上限15%）＋7日異議＋模擬受領→模擬精算 |
| 保管庫 | 独自 | 7日反応なしで保管、需要の地図 |

段階は 0投稿→1形あり→2買い手あり→3納品→4検収→5精算。人の確定でのみ上がる。AIは準備と提示だけ。

## 進め方（役割分担）

各回、GPT-6 に「次に取り込むもの」を決めさせ（`internal/decisions/`）、Claude が実装し、偽物環境で受入条件を通してから公開する。第8版まで：第3回 模擬取引・検収基準・台帳・未読／第4回 型化・比較／第5回 時間・原価比較・版と差分／第6回 固定版と取り込み記録／第7回 参加者・サンプル分離・保管／第8回 手番・二度目の確認。AI席の指示文は `prompts/ai-seat-prompts.json`（GPT-6 下書き）。

## 参加のしかた（仲間内テスト）

1. 共有URLを開き、右上で参加者を登録する（名札。認証ではない）。
2. 「探す」でサンプルを見る。実案件を始めるなら「サンプルから実案件を始める」か、上の欄から「もし」を置く。
3. 「手番」に、自分が次に動くものだけが出る。
4. 機密情報・個人情報・実際の送金情報は入れない。すべて模擬（実決済なし）。

## ディレクトリ

```
proto/            本番ソース（index.html）、検証用（test/：偽物のDB・AIで一周する run*.html と scenario_round*.js）、差分パッチ
mock/             全貌モック（データは例）
prompts/          AI席の指示文（GPT-6 下書き）、UIの作法
internal/         社外秘（企画書・事業モデル案・席の仕組み仕様・判断記録）。公開前に削除
```

特許検討メモと弁理士依頼メモは、このリポジトリに入れていない（別途）。
